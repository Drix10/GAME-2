# Tap-to-Stop Car Game for Android (MIT App Inventor)

A reflex **car game for Android**: tap the car to start it moving and tap again to send it back to the start. Stop it before it reaches the other edge of the screen; every successful tap adds one point. Built with [MIT App Inventor](https://appinventor.mit.edu/), a block-based tool for making Android apps.

## Download

Install the prebuilt APK: [`CARS.apk`](CARS.apk)

## Files

- `CARS.apk`: Android build
- `Screen1 (1).bky`, `Screen1 (2).scm`: blocks and layout
- Game sprites and resource files
